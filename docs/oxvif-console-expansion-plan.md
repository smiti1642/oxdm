# OxDM 指令台擴充計畫

2026-11-13 · 實作計畫

OxDM 指令台要能操作相容版本的 oxvif CLI 中大部分公開命令。提供可摺疊的執行卡片、黑底彩色終端顯示，以及可搜尋、編輯和移除的參數方塊。指令說明、補全和介面使用 OxDM 已支援的英文、繁體中文與俄文。先以單機 `diagnose --share` 和 `events watch` 驗證整條流程，再開放其他命令。

## 命令覆蓋與執行方式

以版本相符的 CLI parser、命令 ID 和 `describe --grammar` 為準，建立逐命令覆蓋清單。每個公開葉節點標記為 OxDM 內執行、外部終端執行，或附明確原因的待支援。相同語義的 alias 指向同一命令 ID，驗收也覆蓋常用 alias。

[逐命令覆蓋與限制](oxvif-console-coverage.md)

- 擴充 CLI 語法的執行 metadata，包括允許的 selector、是否可注入 OxDM 攝影機、輸出契約與退出行為、可取消方式、檔案用途、互動需求及作用範圍。保留舊版本的三條命令相容路徑。新資料不足的命令在介面顯示可用性，執行器依已知能力派送。
- 先支援單機唯讀診斷、裝置與媒體查詢、PTZ 狀態、健康檢查、快照、設定盤點／比較與事件監看，再接探索、批次及 CLI 本機資源。建立、移除或修改裝置登錄、Group／View、快照和憑證等操作，標明實際會修改的 CLI 工作區。需要確認時用既有對話框，顯示對象、影響及可取消的操作。匯入沿用 CLI 的預覽、fingerprint 與套用流程。
- 相機目標在執行前定案。選定裝置與 `--target` 適用現有的認證隔離規則，匹配時才注入單次程序所需憑證。CLI 的 `--device`、Group／View、目前裝置和原生憑證庫屬於 CLI 工作區。清楚顯示作用範圍，避免以 OxDM 裝置 ID 或憑證替代。程序用固定執行檔與 argv 啟動，清除繼承的帳密，秘密以支援的 stdin 或程序環境傳入。歷史、複製、預覽及紀錄均採安全投影。
- `manage` 及依賴真正 TTY 的互動流程提供明確的「在外部終端開啟」入口。平台介面以可驗證的 argv 傳遞，避免命令列拼字串、任意 shell 執行及轉交秘密。若某平台無法安全啟動或缺相容終端，提供經遮蔽、可複製的用法。原生 PTY 可獨立評估。

### 共用 Rust crate

OxDM 的一般裝置頁已直接依賴 `oxvif` 函式庫。指令台另行啟動內附的 `oxdm-oxvif`，透過版本化語法取得補全資料，執行時讀取 JSON／JSONL。`oxvif-cli` 已提供可作為依賴的 library target，公開 `Application::execute`、`Application::watch_events`、`CommandRequest`、`CommandSpec` 及 typed results。Clap 定義和 argv 到 typed request 的轉換目前仍在 binary target，分享報告也有部分流程從 binary 進入。

若改成進程內執行，先在 oxvif 端抽出同一套公開的解析、語法及執行契約，讓 CLI 和 OxDM 共用，並由介面注入登錄檔、憑證、取消和輸出接收端。以兩條路徑對同一組 fixture 驗證 selector、診斷結果及監看取消。`manage` 等真正需要 TTY 的命令繼續透過執行檔啟動。本次擴充先沿用 sidecar 契約，避免命令覆蓋和程序生命週期遷移同時進行。

- 在 `oxvif-cli` 的 library target 提供無 I/O 的 argv 解析與語法匯出，回傳型別化請求、執行選項或互動需求。CLI 的 `main` 負責終端提示、程序環境、訊號和退出碼，OxDM 負責視窗互動和攝影機選擇。兩端以同一份 Clap 定義處理 alias、位置參數、預設值、`--` 與衝突。
- 從 `device info` 與 `events watch` 驗證進程內路徑。一般請求使用 `Application::execute`，監看使用 `Application::watch_events` 的取消 future 與有界接收端。分享診斷移植時，由 library 共用目前的安全報告建立流程及 schema。相機憑證透過單次呼叫傳入，CLI 登錄檔與憑證庫以明確設定注入。
- 保留固定執行檔的相容路徑，供外部終端與使用者指定的 CLI 版本使用。以同一批模擬攝影機及暫存工作區驗證兩條路徑的輸出、錯誤、帳密遮蔽和停止後的退訂，再逐步擴大進程內覆蓋。兩個 crate 的 oxvif 版本需同步，讓 Cargo 共用協議實作。

## 兩種呈現共用執行紀錄

每次執行建立 run ID，保存命令快照、目標標籤、開始與結束時間、退出狀態、結構化結果和有界輸出。先定總筆數、單次輸出與總記憶體上限，保留進行中的 run，淘汰舊結果時明確提示。介面切換、摺疊、換機及捲動都透過同一份紀錄呈現。第一版紀錄放在本次 app 工作階段，需跨重啟留存的結果由使用者明確匯出。

- **一般模式。** 每次執行是一個可摺疊區塊，摘要顯示命令、攝影機、狀態與耗時。展開後依契約呈現結果、錯誤、下一步與可下載檔案。進行中的監看在摘要顯示計數、缺口及停止控制。收合時仍接收事件。單份 JSON、JSONL、純文字、檔案結果及分享報告各有對應呈現。
- **終端模式。** 黑底等寬字，顯示提示符號、彩色輸出與結束碼，保留文字輸入、高亮、補全及歷史。只支援需要的色彩樣式及受控換行，將其他控制序列視為文字或移除，避免外部內容改變終端狀態。標頭分別提供切換卡片／終端模式及離開指令台。Esc 先關閉補全或選機等浮層，再返回卡片模式或離開指令台。切換及離開時保留草稿、執行紀錄與目前執行，重新進入時顯示卡片。終端外觀與真正 TTY 的入口分開。
- **離開指令台。** 頂列終端按鈕可切換，指令台內也提供返回按鈕。從裝置頁或事件頁進入時記住來源頁，離開後可再次開啟指令台查看同一筆執行。選機與是否停止監看由各自的控制處理。
- **分享報告。** 用第一個失敗、下一步與跳過檢查呈現 `diagnose --share`。即使退出碼非零，只要報告驗證通過即可另存。使用者在另存對話框確認位置。分享檔只寫入依版本與欄位白名單驗證的報告，程序 stderr、命令預覽及其他 UI 資料不納入。報告中途截斷、schema 不合或超過上限時，標示無法匯出。`config validate --share` 明示驗證的是 oxvif CLI 的登錄檔及探索快照。

## 指令與參數方塊

一般模式採用結構化草稿。選擇命令後就顯示可用參數，直接輸入 `dur` 可搜尋 `duration`，也可開啟「＋參數」。加入後以 `duration: 30s`、`topic: VideoSource/MotionAlarm`、`quiet: true` 等方塊呈現。可點選、用鍵盤編輯或移除。選項依型別提供輸入欄、選單、數字、時間、檔案選擇或裝置資料。旗標加入即為 true，移除即省略。計數旗標顯示 `verbose: 2`，可重複值以多值方塊保留順序。提供必填、位置參數、互斥、可重複、預設值和有效輸入範圍的回饋。

用命令 ID、參數 ID、操作類型及原始值建立草稿，保留值與位置順序。參數語法從 CLI 的 Clap 匯出，必要時新增 flag、count、single、append、positional 及路徑／敏感值等明確語義。機型相關值沿用目前的 Topic 補全策略，逐步加上 Profile。快取以目標、有效憑證和操作種類隔離，離線仍可手動輸入。

保留貼入完整 CLI 指令、預覽與複製。一般模式和終端模式由同一組解析與 argv 產生規則往返。語法無法完整解析時保留原文字與錯誤位置，等使用者修正。驗證包含引號、空格、Unicode、IPv6、`--flag=value`、`--`、位置與重複參數。編輯器及參數表單保留 IME 和可完整使用鍵盤的流程。

## 英文、繁中與俄文

- 將內附 CLI 的命令、群組、參數、值提示、範例說明和結果狀態以穩定 ID 連到 EN／繁中／RU 字串。說明側欄與補全共用 lookup。命令拼法、旗標、token 及可執行範例維持原語法。
- 可分享報告依 `stage`、`reason`、`action` 顯示在地化結果與下一步，匯出沿用 CLI 報告契約。動態裝置資料或未知的新版 metadata 使用來源文字或英文 fallback，保留其來源。
- 由包裝驗收枚舉已開放的命令和參數，三語皆須可找到說明。以俄文走完選攝影機、搜尋參數、執行、展開錯誤與停止監看，另檢查俄文較長文字的截斷、側欄寬度與鍵盤焦點。

## 施工順序與完成條件

| 工作 | 可驗證成果 |
| --- | --- |
| 1. 命令能力與草稿 | 清點目前 CLI 公開命令及 alias，建立支援清單。新舊 sidecar 相容，典型 argv 與 CLI 實際 parser 一致。未知能力、衝突、錯誤旗標和秘密欄位有明確行為。 |
| 2. `diagnose --share` 端到端 | 沒選攝影機時可從介面選定。用方塊填參數，在可摺疊卡片讀失敗與下一步，另存可驗證 JSON，再切到黑底終端模式查看同次執行。測試錯誤退出、輸出截斷及合成帳密與私有資料隔離。 |
| 3. `events watch` 與執行紀錄 | 用既有 MockServer 驗證串流、事件暴增、續租、切換模式、摺疊、停止、取消訂閱、匯出與有界記憶體。換攝影機後舊執行仍屬於原裝置。 |
| 4. 擴大覆蓋和三語說明 | 逐批完成唯讀、探索／批次及本機維運命令，最後接外部終端。逐命令驗證執行路由、選擇器、輸出、確認、秘密處理和 EN／繁中／RU 說明。覆蓋清單中每項都有執行入口或具體限制。 |
| 5. 交付與盲測 | 用相容 sidecar 產出本地 Windows MSI，驗證套件內附 CLI 和相容版本。用未看過操作步驟的測試者完成無相機選定時查詢、三語說明、參數方塊、兩種模式與摺疊，再完成安全報告與事件停止。記錄 Windows 原生驗收證據及其他平台和實機的驗收狀態。 |

這份計畫的本地交付以實作、回歸、Windows MSI 和盲測結果為完成條件。推送、發布、macOS DMG 與實體攝影機驗收沿用後續安排。
